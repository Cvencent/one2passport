# 首页轻量运行与应用按需加载

用户目标：首页只显示机器人任务状态与当前电台，不切台、不浏览任务；进入菜单应用才提供完整操作。首页的任务完成/失败通知继续生效。

方案：使用同一收音机音频核心和同一 Codex 连接，避免两份播放器或两条连接。完整页面及渲染临时缓冲按进入/退出分配与释放。Codex 首页保留任务状态、结果身份和通知，禁止自动请求项目列表。收音机首页使用缓存目录，不自动定位与搜索；完整应用进入后按需刷新目录。退出收音机保留用户正在听的电台，只销毁完整操作页面。

MP3 解码器必须保留早期预热：设备没有 PSRAM，Wi-Fi 启动后无法可靠取得约 20KB 连续块。首页若播放音频，解码器/TCP/PCM 均不可省略。先通过回收 Codex 渲染缓存与隐藏的收音机页面获取空间，避免关闭解码器导致重新进入收音机永远无法播放。

错误行为：内存申请失败应返回菜单，不创建半成品页面。目录请求失败保留原目录，不覆盖缓存。网络恢复时只在完整收音机应用内触发目录搜索。

验证：主机侧生命周期测试检查轻量态无完整缓冲、重复进出正确释放、失败分配回滚；构建并刷机后核对首页堆与目录任务，进入收音机取得 PCM，切台、退出到首页与再次进入，重启目录缓存。当前修复未实测通过前不宣称所有电台已恢复。
